# 环境与协作

运行环境：**Ubuntu 22.04 + Qt5（qmake）+ SQLite**。不要用 Windows 的 qmake 编。

- 用户端：只连 TCP `IP:8888`，禁止打开 `.db`
- 管理端：唯一写库进程，同时听 8888；全组联调只能开一份
- 大屏：Python3 + Flask，前端 Vue 3（`<script setup>`）+ ECharts，只读同一份库 + `bigdata/output/spark_report.json`，端口 5000
- 大数据：Hadoop 3.3.6 + Spark 3.5.x + PySpark，见 [大数据与智能分析.md](大数据与智能分析.md)

操作步骤、网络基础、多管理端冲突、模块接口、表结构见仓库根目录 **[README.md](../README.md)**。报文见 `protocol/messages.md`，建表见 `database/schema.sql`。
