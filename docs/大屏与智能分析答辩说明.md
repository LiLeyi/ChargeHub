## 1. 这条链在系统里干什么

三类界面里，大屏是 **只读会议室电视**：

| 角色 | 程序 | 能不能改订单/余额/桩 |
|------|------|----------------------|
| 管理端 | `adminserver` Qt，听 `:8888` | **唯一能写业务库** |
| 用户端 | `userclient` Qt | 只能打 Socket，禁止打开 `.db` |
| 运营大屏 | 浏览器 + Flask `:5000` | **全部 SELECT / 读 JSON，没有 POST** |

智能分析的数字 **不是** 在浏览器里训练出来的。训练在 WSL 里跑完，写成 JSON，大屏只负责画。

```
dataset/04.数据集最终版/*.csv          真实样本（约 3.4k 会话 + 电池遥测）
        │
        ▼ expand_dataset.py            按真实分布加噪声扩到约 22 万会话
dataset/big/sessions.csv + stations.csv + telemetry.csv
        │
        ├─（可选）ingest_hdfs.sh → hdfs://localhost:9000/chargehub/dataset
        │
        ▼ spark_analyze.py             GBT/RF/LR、KMeans+PCA、IF、RFM、逻辑回归、FP-Growth、电池分
bigdata/output/spark_report.json
        │
        ├─ enrich_dashboard.py ──► dash_charts.json     （日趋势/SOC/RFM散点/7日预测/质量）
        ├─ apply_results.py    ──► analysis_* 表        （只这六张派生表）
        │
        ▼ dashboard/app.py  GET /api/overview|/api/analysis|/api/bigdata
        ▼ dashboard/web     Vue 3 + ECharts 六页签
```

HDFS 没起来时，`spark_analyze.resolve_input` 会改读 `file:///dataset/big`，作业照样出图。`engine` 字段会显示 `HDFS` 或 `LOCAL`。

## 3. Flask 接口（大屏前端主讲怎么打开；可视化只记 JSON 形状）

实现：`dashboard/app.py`。绑定 `0.0.0.0:5000`，`debug=False`。

| 方法 | 路径 | 函数 | 用途 |
|------|------|------|------|
| GET | `/` | `index` | 返回 `dashboard/dist/index.html` |
| GET | `/api/overview` | `overview` | 业务库营收、桩、闲置 |
| GET | `/api/analysis` | `analysis` | 负荷/告警；优先 Spark JSON |
| GET | `/api/bigdata` | `bigdata` | 机器学习报告 + `charts` |
| GET | `/api/tariffs` | `tariffs` | 分时电价只读，无 POST |

找库：`findDb()`。找 Spark：`findSparkReport()`。图表：`loadCharts()` 有缓存，重启 Flask 才换新 JSON。`q()` 表不存在返回空列表。金额单位元。

## 5. Spark 算法与函数对照（机器学习细拆；管道只讲 main 怎么调用）

模型函数都在 `bigdata/spark_analyze.py`。`main()` 由**机器学习**串联；HDFS 读哪条路径由 **Hadoop** 同学讲 `resolve_input`。

| 函数 | 算法 | 输入 / 规则 | 输出键 | 大屏落点 |
|------|------|-------------|--------|----------|
| `train_models` | GBT + 随机森林 + 线性回归 | 小时、星期、时长、电站/平台、车队、设施 → 预测 kWh | `models` `importances` | 智能预测 |
| `hourly_and_forecast` | 历史/90 天 + GBT 混合 | 24 点典型日；窗口 1/6/24h | `hourly` `forecasts` | 负荷图 |
| `cluster_stations` | KMeans + PCA | 会话数、均电量、均时长、均费用、均开充小时 | `pca_x/y/label` | 电站画像 |
| `name_station_clusters` | 相对排序命名 | 禁用 hour>=17 绝对阈值 | 簇名 | 同上 |
| `user_rfm` | KMeans on R/F/M | 近度、频次、金额 | `rfm` | 风险页 RFM 条 |
| `peak_classifier` | 逻辑回归 | 是否 17–21 点开充 | `peak_clf` | 报告 |
| `isolation_anomalies` | IsolationForest / 99 分位 | 小时、kWh、时长、费用 | `anomalies` | 告警 |
| `assoc_rules` | FP-Growth | 星期 × 峰谷 × 平台 | `rules` | JSON |
| `battery_risks` | 加权评分 | 高温、压差、电流、低 SOC | `battery` | 故障风险 |
| `weekday_hour` | 聚合 | 星期×小时电量 | `heatmap` | 热力 |
| `build_alerts` | 规则 | 高峰、电池、异常计数 | `alerts` | 告警条 |

`enrich_dashboard.py` 不是 Spark：

| 函数 | 谁讲 | 作用 |
|------|------|------|
| `scan_quality` `fix_year` `read_csv_rows` | 数据清洗 | 原始 nvv2t / dsv13r2 异常与漏斗 |
| `rfm_pack` `metrics` | 机器学习 | 高价值/流失评分、误差指标 |
| `scan_sessions` `build` `forecast_7` | 机器学习 | 扫扩样表写成 dash_charts.json |

### 1. HDFS 与 Hadoop

主技术：Hadoop 单节点 HDFS。不讲 GBT，不扩样，不改 `.vue`。

必看：`conf/core-site.xml`；`conf/hdfs-site.xml`；`scripts/setup_hadoop_spark.sh`（JDK+Hadoop 段）；`start_hdfs.sh`；`ingest_hdfs.sh`；`paths.py` 的 `hdfs_uri` `input_uri`；`spark_analyze.py` 的 `_try_hdfs_ls` `resolve_input`；`spark-defaults.conf` 里的 `spark.hadoop.fs.defaultFS`。

必讲：`fs.defaultFS = hdfs://localhost:9000`。副本数 `dfs.replication=1`，一台 WSL 里 NameNode+DataNode。`hdfs dfs -put` 把 `dataset/big` 放到 `/chargehub/dataset`。机器学习作业优先读这条 URI；NameNode 没起来则 `resolve_input` 改本地 `file://`，大屏 `engine` 会显示 LOCAL。这是**单机上的 Hadoop 接口与存储**，不是多机集群。

不管：树深度、Vue、清洗漏斗字段、`expand_dataset` 噪声怎么加。
