# ChargeHub 测试用例

每条：前置 / 步骤 / 期望。多用户冒烟：`python3 tests/testmultiuser.py`（管理端须已监听 8888）。

| 编号 | 前置 | 步骤 | 期望 |
|------|------|------|------|
| T01 | 用户端已启动 | 输入 12345 登录 | 提示手机号格式错误 |
| T02 | 库中无该号 | 注册 11 位号 + 密码 | 注册成功，余额 0 |
| T03 | T02 已完成 | 同号再注册 | 409 该账号已注册 |
| T04 | 用户已冻结 | 登录 | 403 账号已冻结 |
| T05 | 用户已注销 | 登录 / 再注册 | 403 留档无法登录；409 无法再注册 |
| T06 | 新用户余额 0 | 启动充电 | 余额不足 |
| T07 | 有余额且桩闲置 | 启动充电 | 订单充电中，桩在用 |
| T08 | 充电中 | 再启动另一桩 | 提示先结算 |
| T09 | 充电中 | 结束充电并结算 | 订单已完成，余额减少，桩闲置 |
| T10 | 管理员 | 密码错误 | 账号或密码错误 |
| T11 | 电桩在用 | 远程重启 | 拒绝 |
| T12 | 故障桩 | 远程重启 | 变为闲置 |
| T13 | 已完成订单 | 销售业绩 | 计入今日营收；待结算不计入 |
| T14 | 无未完成订单 | 注销账号 | status=注销，记录仍在库中 |
