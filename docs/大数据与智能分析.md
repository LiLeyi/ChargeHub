# 大数据与智能分析

技术栈：**WSL Ubuntu 22.04 + OpenJDK 11 + Hadoop 3.3.6（单节点 HDFS）+ Spark 3.5.x + PySpark**。  
PyCharm 用 WSL 解释器打开 `ChargeHub/bigdata`，步骤见 [../bigdata/README.md](../bigdata/README.md)。

挖掘方法：GBT / 随机森林 / 线性回归、KMeans+PCA、IsolationForest、用户 RFM、晚高峰逻辑回归、FP-Growth、电池风险。大屏只展示数字与图，算法说明留在本页。

**五人答辩分工、函数对照、代码位置：**见 [大屏与智能分析答辩说明.md](大屏与智能分析答辩说明.md)。函数级注释在各 `.py` 的 docstring 与 `dashboard/web` 的 JSDoc。

## 数据

| 文件 | 含义 |
|------|------|
| `dataset/04.数据集最终版/nvv2t.csv` | 真实充电会话（约 3.4k） |
| `dataset/04.数据集最终版/nvv2t_md_end.csv` | 电站维表 |
| `dataset/04.数据集最终版/dsv13r2.csv` | 电池包遥测 |
| `dataset/big/sessions.csv` 等 | 扩样后的模拟生产集（默认 22 万会话） |

扩样只加噪声复制分布，不碰业务库。

## 和现有模块怎么接

```
dataset/big → HDFS 或 file:// → spark_analyze.py
        → bigdata/output/spark_report.json
        → dashboard GET /api/bigdata（可视化）
        → apply_results.py 只写 analysis_* 表
        → 管理端智能分析页 / 大屏 /api/analysis
```

`AnalyticsService::refreshForecast`：若已有 Spark 报告则导入分析表，否则回退小时均值。  
Socket 金额仍是元；用户端仍不打开 SQLite。
