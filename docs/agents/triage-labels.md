# Triage Labels

工程技能使用以下五种标准分诊角色。右列是本项目 GitHub Issues 中应使用的实际标签。

| 标准角色 | 实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由智能体独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到标准角色时，使用表格中对应的实际标签。若 GitHub 标签名称以后发生变化，只需更新本表右列。
