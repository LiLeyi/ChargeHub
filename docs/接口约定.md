# ChargeHub HTTP 接口（运营大屏）

大屏 Flask **只读** SQLite，不改订单、余额、桩状态。默认 `0.0.0.0:5000`。

实现与每个 JSON 字段的注释在 `dashboard/app.py`（模块 docstring 与各视图函数）。

五人答辩时按页签拆代码：见 [大屏与智能分析答辩说明.md](大屏与智能分析答辩说明.md)。

用户端业务仍走 Socket，见 `protocol/messages.md`。地图/天气出站 HTTP 见 `common/tencentapi.h`，不经过本服务。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 大屏页面（Vue 3 多屏：运营总览 / 行为分析 / 智能预测 / 用户分析 / 风险调度） |
| GET | `/api/overview` | 今日/本月营收、桩状态、趋势、地图点 |
| GET | `/api/analysis` | 负荷预测、故障风险、告警、调度建议（含 `adopted`） |
| GET | `/api/bigdata` | Spark 报告 + `charts`（日趋势、SOC、RFM 散点、7 日预测等） |
| GET | `/api/tariffs` | 分时电价只读列表 |

`/api/tariffs` 每行：`stationId`、`station`、`startHour`、`endHour`、`pricePerKwh`、`label`。无规则的站不会出现。启用/改价只在管理端 GUI 做，大屏不提供 POST。
