# 腾讯地图位置与导航

用户端的“位置 / 导航”会使用腾讯位置服务：

- 电站卡片显示地址、纬度和经度；
- 位置窗口加载腾讯静态地图；
- 可选择驾车、步行、骑行或公交，查询路线距离和预计时间；
- 也可以直接打开腾讯地图网页完成导航。

腾讯地图 Key 已作为客户端默认配置使用。若该 Key 开启了签名校验，请在启动用户端前配置 SK（不要把 SK 提交到 Git）：

```powershell
$env:CHARGEHUB_TENCENT_MAP_SK = "你的腾讯地图 SK"
```

Linux/macOS：

```bash
export CHARGEHUB_TENCENT_MAP_SK='你的腾讯地图 SK'
```

也可以通过 `CHARGEHUB_TENCENT_MAP_KEY` 覆盖默认 Key。环境变量需要在启动 `userclient` 或 `scripts/rebuild.sh` 前设置。
